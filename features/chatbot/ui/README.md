# Chatbot arayüzü

Konuşma penceresi, mesaj listesi, gönderim formu ve yükleniyor/hata durumları burada geliştirilir. Sunucu modüllerini istemci bileşenlerine import etmeyin; yalnızca `../contracts` tiplerini ve HTTP sözleşmesini kullanın.

Widget ilk yüklemeyi ağırlaştırmamalı; dokunma, klavye, odak yönetimi ve azaltılmış hareket tercihini desteklemeli. Model çıktısını ham HTML olarak göstermeyin. Henüz bu klasörde canlı bileşen yoktur.
